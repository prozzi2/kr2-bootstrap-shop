# kr2-bootstrap-shop — Shop_ot_bob на Bootstrap

Учебный интернет-магазин **Shop_ot_bob**: руки для армрестлинга и для повседневной жизни. Проект выполнен в рамках дисциплины «Фронтенд и бэкенд разработка».

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

КР №2 — отдельная реализация той же предметной области, что и в КР №1 ([kr1-html-css-shop](https://github.com/prozzi2/kr1-html-css-shop)), но интерфейс построен на CSS-фреймворке, а не на собственном CSS.

## Используемый фреймворк

Bootstrap 5.3.8 (CSS + JS Bundle). Шрифт заголовков — Russo One (Google Fonts).

## Способ подключения Bootstrap

Bootstrap подключён через CDN (jsDelivr): CSS в `<head>` до `css/custom.css`, JS Bundle перед `</body>`.

## Bootstrap-сетка

- `container`, `container-fluid` (hero-блок на всю ширину);
- `row`, `col-*`, `col-12`, `col-sm-*`, `col-md-*`, `col-lg-*`, `col-xl-*`;
- отступы между колонками — `g-3`, `g-4`, `g-5`, `g-0`;
- карточки каталога: 1 колонка на телефоне → 2 на `sm` → 3 на `xl`;
- популярные товары: 1 → 2 (`md`) → 3 (`lg`); преимущества: 1 → 2 → 4.

## Реализованные Bootstrap-компоненты

Обязательные:

- `navbar` (с `dropdown` и мобильным меню через `collapse`) — на всех страницах;
- `card` — карточки товаров, форм, сводки заказа;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-warning`, `btn-light`, `btn-outline-secondary`, `btn-link`;
- `badge` — «Хит», «Новинка», «Скидка», «Под заказ», теги стороны/пола/назначения;
- `alert` — подсказки в каталоге и форме, предупреждение для бытовых моделей, сообщение об успешной заявке;
- `modal` — быстрая заявка (`#orderModal`), открывается из navbar, карточек и страницы товара;
- формы — `form-control`, `form-select`, `input-group`, `form-check`, `form-switch`, `form-range`, `btn-check`, валидация `was-validated` / `invalid-feedback`.

Дополнительные:

- `carousel` — акции на главной;
- `accordion` — частые вопросы на странице товара;
- `nav-tabs` — описание / характеристики / доставка товара;
- `pagination` — постраничный вывод каталога;
- `toast` — уведомления после отправки форм;
- `breadcrumb` — навигационная цепочка;
- `collapse` — панель фильтров на мобильных;
- `btn-group`, `list-group`, `table`, `ratio`.

## Самостоятельные доработки

1. **Дополнительная страница** `contacts.html` — контакты, блок «О магазине», форма обратной связи с валидацией, карта.
2. **Каталог с фильтрами** — поиск по названию, назначение (checkbox), сторона (`btn-group`), пол (radio), цена (`form-range`), «только в наличии» (`form-switch`), сортировка, пагинация по 6 товаров, сообщение «ничего не найдено». Ссылки `catalog.html?category=sport` / `?category=daily` из меню сразу включают нужный фильтр.
3. **Единая карточка товара** — `product.html?id=N` заполняется данными нужного товара через JavaScript (название, цена, старая цена, badge, наличие, характеристики, похожие товары).
4. **Улучшенный сценарий заявки** — товар подставляется из `order.html?product=N` и из кнопки карточки в модальное окно; количество меняется кнопками `−`/`+`; сводка заказа считает сумму и доставку (курьер бесплатно от 30 000 ₽); после отправки — `alert` и `toast`.
5. **Валидация форм** в стиле Bootstrap (`needs-validation`, `invalid-feedback`), очистка телефона от лишних символов.
6. **Визуальная целостность** — фирменные цвета и шрифт, градиентный hero, единые карточки с hover-эффектом, подчёркивание заголовков разделов; учтён `prefers-reduced-motion`.
7. **Адаптивность** — проверено на 375, 768, 1366 px: нет горизонтальной прокрутки, фильтры сворачиваются, карта меняет пропорции на телефоне.

## Как проверить проект

1. Открыть `index.html`.
2. В DevTools включить мобильный режим (375 px) — меню сворачивается в кнопку и раскрывается.
3. На главной: карусель листается, «Быстрая заявка» открывает модальное окно.
4. В каталоге: изменить фильтры и сортировку, перейти на 2-ю страницу; ввести в поиск несуществующее название — появится `alert`.
5. Нажать «Заказать» у товара — в модальном окне уже выбран этот товар; отправить пустую форму — появятся подсказки; заполнить — появится `toast`.
6. Открыть `product.html?id=6` — бытовая модель «Под заказ» с предупреждением; переключить вкладки, раскрыть accordion.
7. На `order.html?product=1` изменить количество и доставку — пересчитывается итог; отправить форму.

Формы учебные: данные проверяются в браузере и не отправляются на сервер.
